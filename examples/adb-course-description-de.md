# Agentic Development Basics (fiktiv)

In 90 Minuten lernen Developer, wie ein Coding-Agent plant, handelt und seine Arbeit prüft. Die Teilnehmenden schreiben selbst einen Auftrag für einen Agenten und erleben, welche Angaben Rückfragen ersparen.

Ein Schwerpunkt ist der sichere Umgang mit dem, was ein Agent liefert: Wir zeigen eine Checkliste, mit der sich vorgeschlagene Änderungen vor dem Mergen prüfen lassen.

Zum Abschluss entwirft jede Gruppe eine Arbeitsvereinbarung, wann ein Agent einen Pull Request öffnen darf.
